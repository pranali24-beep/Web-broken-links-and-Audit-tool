Project Overview

Website Broken Link & SEO Health Audit Tool

The Website Broken Link & SEO Health Audit Tool is designed to analyze websites for broken links and common on-page SEO issues. Developed as a 2nd-year Information Technology Engineering semester project, it provides webmasters, students, and site owners with an automated diagnostic tool to inspect domain integrity, identify 404/500 link failures, and optimize search engine visibility.

The tool bridges the gap between complex enterprise SEO suites and simple link checkers by providing a clear, readable visual dashboard with actionable recommendations, severity rankings, and composite scoring.

Core Goals

Project Objectives

The system is architected to address core challenges in web maintenance and search engine optimization.

Detect Broken Links

Crawl interconnected web pages and test every hyperlinked resource for HTTP 404 (Not Found), 500 (Server Error), and timeout conditions across internal and external targets.

Identify Basic SEO Issues

Analyze key on-page SEO attributes including title tag presence and uniqueness, meta description completeness, single H1 heading hierarchy, and image alt text accessibility.

Provide an Understandable Health Score

Synthesize audit findings into an intuitive 0–100 numerical health rating with clear status categories (Good, Needs Improvement, Critical) to aid decision making.

Present Audit Findings Clearly

Deliver clean tabular reports, severity badges, and structured breakdown summaries so web developers and site owners can locate and remediate flaws efficiently.

Maintain Audit History

Store historical audit snapshots to track SEO progression, monitor recurring broken links, and measure health score improvement across multiple website iterations.

Tech Stack & Roadmap

Technology & Development Roadmap

A staged engineering approach dividing presentation design from crawler engine and backend persistence.

Current Stage (Active)

Frontend Presentation Layer

Built using semantic HTML5 and modular CSS3 with zero heavy framework dependencies. Employs CSS Grid, Flexbox, custom variables, responsive media queries, and pure CSS circular data visualizations.

HTML5 Semantic Elements CSS3 Custom Variables CSS Grid & Flexbox Pure CSS Conic Gauge Responsive Design
Future Stage (Planned Backend)

Crawler & Analysis Backend

In subsequent phases, a Python / Flask server will crawl target domains using Requests & BeautifulSoup4, compute SEO metrics, and persist audit history in a SQLite database.
